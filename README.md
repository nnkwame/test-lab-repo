# test-lab-repo (Hello, Git Flow)

## About
Site for teaching about git branching, from basics through intermediate to advanced concepts. 

## Features
- Contains links to helpful resources to git learning as well as interactive material (eg games).
- User can switch between Light and Dark themes based on a JS-powered button in the nav bar. The button togglesd back and forth on successive clicks.
